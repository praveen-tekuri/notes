## 1. Introduction

- A database is a system designed to store and organize data for quick retrieval. If you've tracked the delivery of an online purchase, received a digital receipt, streamed a movie, or updated your contact information in a mobile app, you were interacting with a database system.
- A database stores and organizes data, making sure it’s quickly available to applications, websites, and users when requested.
- A database management system (DBMS) is a database software layer that manages the data in cloud databases or on-premises databases.
- Popular database categories include relational (SQL) and non-relational (NoSQL); the NoSQL category offers specialized types such as document, key-value, and vector databases
- The best type of database to use depends on what kind of data is stored—and why and how the data is retrieved.

> What is a database used for?

- Databases are used for various data processing operations, the most basic being the Create, Read, Update, and Delete (CRUD) operations.
- Applications use databases via programming language code to store or get the necessary data. For example, when you create an online profile on a social media platform, the data you provide is stored in a database for future use.

- Source (https://www.mongodb.com/resources/basics/databases/databases)

> Type of Databases
- There are so many types of databases like relational database, NoSQL database, in memory database etc,. every database servers the different purpose.
- Most companies use relational databases(mySQL, PostgresSQL) and NoSQL databases(mongoDB)
- Big companies will use different databases for different challenges and requirements.
> Relational vs NoSQL(Document) databases
- `SQL databases` are relational databases that store structured data in tables with a fixed schema, meaning the structure of the data—such as columns, their data types, and constraints—is defined before inserting data. They are well suited for complex relationships, joins, and strong transactional consistency. `NoSQL databases` use models such as documents, key-value, column-family, or graphs and generally provide a flexible schema, meaning different records/documents can have different fields and structures without requiring the entire database structure to be changed. They are often designed for high scalability and large, distributed workloads. The choice depends on the application's data structure, relationships, consistency requirements, and scalability needs.
- RDBMS organizes data into databases, which contain `tables`. tables are compose of `rows` and `columns`
- MongoDB organizes data into databases, which contain `collections`. collections are composed of `documents` and `fields`.

## 2. Creating a Database

- To connect nodeJS to mongoDB, we need `mongodb` npm package,
- `npm i mongodb` (installs mongodb package)
    - NPM is a repository of packages(node modules) that you can use in your NodeJS applications. it's essentially a package manger for nodeJS.

    ```js
    // database.js

    const {MongoClient} = require("mongodb");
    
    // Connection URL // connection string // kind of authentication
    const url = "URL";

    // Creating  new object from MongoClient and passing the url
    const client = new MongoClient(url);

    // Database Name (get it from mongodbCompass that you have created)
    const dbName = 'NodeJSBasics';

    async function main(){
        await client.connect(); // connecting to the server
        console.log('Connected successfully to server');

        const db = client.db(dbName); // referencing the database and getting the database that we have created e.g "NodeJSBasics"
        const collection = db.collection("Users"); // referencing the collection that we have created e.g "Users"
        
        return "done.";
    }

    main()
    .then(console.log)
    .catch(console.error)
    .finally(() => client.close());
    ```
 - USE `connect` method to connect to the server.
 
 - `client.connect()` will request the URL and it will connect to the client, once it is connected, it will log to the console 
 "connected successfully to server".

 - So you're connecting to the server, then you're referencing the database and getting the database, and also referencing the collection.

 - when you call the `main` function, it will return a promise, and that promise then goes through the console.log, 
 and then catch the errors, and finally you wil close the client. SO once you're done running all the code, you finally close the 
 client.

 - Note: first open mongodbCompass or any other tool to access the data, establish the connection using the connection string, then run the database.js using the command "node database.js".

 - NOW you're ready to connect your mongoDB cluster and perform operations from your nodeJS code.

> Mongoose Library

- To make your life easier when connecting to MongoDB, you can use the `Mongoose` library, which is an `Object Data Modeling(ODM)` library for MongoDB and NodeJS. it simplifies the interaction with MongoDB by providing schema-based solutions for modeling your data and handling queries.

- Steps to connect to mongoDB using Mongoose:
    1. Instal Mongoose => `npm i mongoose`
    2. Connect to MongoDB with Mongoose

    ```js
    // database.js

    const mongoose = require('mongoose');

    // Connection URL
    const url = "url";

    // Function to connect to mongoDB using Mongoose
    const connectDB = async () => {
        await mongoose.connect(url);
    }

    connectDB()
        .then(() => {
            console.log("Database connection established...");
        })
        .catch((err) => {
            console.log("Database cannot be connected" + err);
        })
    ```
- Advantages of Using Mongoose:
    - `Schema Definitions:` Mongoose allows you to define schemas for your collections, which helps enforce structure in your documents.
    - `Built-in Validation:` Mongoose provides validation at the schema level, ensuring your data is clean and consistent.
    - `Middleware:` You can use pre and post hooks in Mongoose for tasks like data validation, logging, or transforming data before saving.


## 3. Adding data to the database

To add information to the database we have to take 4 steps:

1. Create a Schema with help of mongoose
2. Create a Class based on the Schema, sometimes it is called to create a class or to create a model.
3. Create an Object based on the Class or Model.
4. Add this Object to the mongoDB database, as a result the object will be stored as a document.
